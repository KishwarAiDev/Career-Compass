# 🧭 Career Compass: ETL + EDA Pipeline

An end-to-end data engineering and exploratory data analysis project built for Pakistan's job market and youth unemployment trends.

## 🚀 Features
- **ETL Pipeline:** Extracts job postings data, transforms and validates records using Pandas and Pydantic, and stores them in a SQLite database (`data/career.db`).
- **Macro Analysis:** Integrates World Bank API data to analyze youth unemployment trends in Pakistan.
- **Interactive Web App:** Built with Streamlit to filter jobs by degree, experience level, city, and skills, providing smart recommendations on what to learn next.

## 🛠️ Tech Stack
- Python
- Pandas, Pydantic
- Streamlit
- SQLite
- Requests (World Bank & API integrations)
